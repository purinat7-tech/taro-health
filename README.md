# 🐱 Taro Health — สมุดสุขภาพทาโร่

เว็บแอปติดตามค่าไต หัวใจ น้ำหนัก และการหายใจของแมว — ดีไซน์สไตล์ fintech dashboard (sidebar + topbar + card-based UI)

---

## ✨ ฟีเจอร์ใหม่: ปริมาณยาคงเหลือ + คำนวณวันเบิกยาใหม่

### วิธีใช้งาน
ในหน้า **"💊 ยาที่ใช้ประจำ"** เมื่อกรอกข้อมูลยาแล้ว จะมีส่วนเพิ่มเติมชื่อ **"📦 คลังยา"** (ไม่บังคับกรอก) ประกอบด้วย:

| ช่อง | คำอธิบาย |
|---|---|
| **จำนวนที่ได้รับ (สต็อก)** | จำนวนทั้งหมดที่ได้รับมาจากร้านยา/รพ. เช่น 30 |
| **หน่วย** | เช่น เม็ด, ml, แคปซูล (ค่าเริ่มต้น = เม็ด) |
| **จำนวนต่อโดส** | ปริมาณที่กินต่อครั้ง เช่น 0.25 สำหรับ "1/4 เม็ด" |
| **ครั้ง/วัน** | จำนวนครั้งที่กินต่อวัน — ระบบ auto-fill ให้จากช่อง "เวลาที่กิน" อัตโนมัติ (นับจำนวนเวลาที่คั่นด้วยจุลภาค) แต่แก้ไขเองได้ เผื่อกรณี "ทุก 2 วัน" ให้ใส่ 0.5 |
| **วันที่รับยานี้** | วันที่เริ่มนับสต็อกก้อนนี้ (ปกติ = วันเริ่มกิน) |

**ตัวอย่าง:** ได้ยา 30 เม็ด กิน 1/4 เม็ด วันละ 2 ครั้ง → ใส่ สต็อก=30, จำนวนต่อโดส=0.25, ครั้ง/วัน=2 → ระบบคำนวณให้อัตโนมัติว่า:
- ใช้ได้ทั้งหมด **60 วัน**
- ตอนนี้เหลือเท่าไหร่ (คำนวณจากวันที่ผ่านไปแล้ว)
- **ควรไปเบิกยาใหม่วันที่เท่าไหร่**

### สิ่งที่ระบบทำให้อัตโนมัติ
1. **คอลัมน์ใหม่ในตารางยา**: "คงเหลือ" (จำนวน+หน่วย) และ "ควรเบิกก่อน" (วันที่ + จำนวนวันที่เหลือ) พร้อมสีเตือน:
   - 🟢 เขียว = เหลือมากกว่า 7 วัน (ยังไม่ต้องกังวล)
   - 🟠 ส้ม = เหลือ ≤7 วัน (เริ่มวางแผนไปเบิก)
   - 🔴 แดง = เหลือ ≤3 วัน (ควรรีบไปเบิกด่วน)
   *(ปรับเกณฑ์วันได้ที่ตัวแปร `REFILL_WARN_DAYS` / `REFILL_DANGER_DAYS` ต้นไฟล์ `app.js`)*
2. **เรียงลำดับอัตโนมัติ**: ยาที่ใกล้หมดที่สุดจะขึ้นแสดงบนสุดของตารางเสมอ
3. **แถบแจ้งเตือน**: ถ้ามียาใกล้หมด (≤7 วัน) จะมีแถบเตือนสีส้ม/แดงขึ้นทั้งที่**หน้ายาที่ใช้ประจำ**และ**หน้าภาพรวม (Home)** พร้อมบอกชื่อยาและวันที่ควรไปเบิก
4. **Badge แจ้งเตือนที่เมนู**: เลขสีแดงจะขึ้นข้างเมนู "ยาที่ใช้ประจำ" ใน sidebar บอกจำนวนรายการที่ใกล้หมด
5. **ปุ่ม "🔄 เติมยา"**: กดที่แถวยาใดก็ได้ในตาราง จะมีกล่องให้กรอกจำนวนที่เพิ่งไปรับมาใหม่ กดยืนยันแล้วระบบจะรีเซ็ตวันเริ่มนับสต็อกเป็นวันนี้ทันที ไม่ต้องแก้ฟอร์มยาวๆ ทุกครั้งที่ไปเบิกยา

### หมายเหตุสำคัญ
- ฟีเจอร์นี้เป็น**ตัวช่วยประมาณการ**เท่านั้น อาจคลาดเคลื่อนได้หากลืมให้ยาบางมื้อ หรือปรับขนาดยากลางทาง — ควรเช็คจำนวนจริงเป็นระยะ
- ยาที่ยังไม่ได้กรอกข้อมูลคลังยา (3 ช่องหลัก: สต็อก/จำนวนต่อโดส/ครั้งต่อวัน) จะแสดง "-" ในคอลัมน์คงเหลือ ไม่กระทบการใช้งานส่วนอื่น
- ข้อมูลยาเดิมที่เคยบันทึกไว้ก่อนอัปเดตนี้ (ไม่มีข้อมูลคลังยา) จะยังใช้งานได้ปกติทุกอย่าง เพียงแค่ยังไม่มีการคำนวณวันเบิกจนกว่าจะกด "แก้ไข" แล้วเติมข้อมูลคลังยาเพิ่ม

## 🚀 วิธีอัปเดตโค้ด

### วิธีที่ 1: อัปโหลดผ่านเว็บ GitHub
1. เข้า repo `taro-health` → **Add file → Upload files** → ลากไฟล์ทั้งหมดวางทีเดียว
2. Commit changes → รอ 30–60 วิ
3. เปิด **Private/Incognito window ใหม่** เข้าลิงก์อีกครั้ง (กันแคชเก่า)

### วิธีที่ 2: Git command line
```bash
cd ~/Desktop/taro-health   # โฟลเดอร์ที่ clone ไว้แล้ว
git add -A
git commit -m "เพิ่มฟังก์ชันปริมาณยาคงเหลือและคำนวณวันเบิกยาใหม่"
git push origin main
```

## 🧪 วิธีทดสอบฟีเจอร์ใหม่

1. เข้าหน้า **"💊 ยาที่ใช้ประจำ"** กรอกข้อมูลยาที่ทาโร่ใช้จริง
2. เลื่อนลงมาที่ส่วน **"📦 คลังยา"** กรอกจำนวนที่ได้รับ + จำนวนต่อโดส + ครั้ง/วัน + วันที่รับยา
3. กดบันทึก → ควรเห็นคอลัมน์ "คงเหลือ" และ "ควรเบิกก่อน" ขึ้นในตารางทันที
4. ลองกรอกยาที่ใกล้หมด (เช่น เหลือน้อยกว่า 7 วัน) → ควรเห็นแถบเตือนสีส้ม/แดงขึ้นทั้งหน้ายาและหน้า Home พร้อม badge ตัวเลขที่เมนู
5. กดปุ่ม **"🔄 เติมยา"** ที่แถวยานั้น → กรอกจำนวนใหม่ → ควรเห็นวันที่เบิกใหม่เลื่อนออกไป และแถบเตือนหายไป (ถ้าพ้นเกณฑ์แล้ว)

## ✅ ฟีเจอร์เดิมทั้งหมดยังอยู่ครบ
- Sidebar + Topbar + 7 หน้า (ภาพรวม/คลินิก/หัวใจ/ยา/หายใจ/ผลเลือด/ตั้งค่า) + Bottom nav บนมือถือ + โหมดมืด
- ระบบรหัสครอบครัว (Family PIN) + ซิงค์เรียลไทม์ผ่าน Firebase
- Popup แจ้งเตือนฉุกเฉินเมื่อ RRR > 45 พร้อมแนะนำคลินิกตามเวลาปัจจุบัน
- ประวัติ Echo พร้อมค่าตัวเลข IVSd/LA:Ao/LAFS/LVFS/LVPWd และช่องข้อความเต็ม/สรุป AI
- กราฟผลเลือด (น้ำหนัก/Creatinine/BUN/ALT) พร้อมหมายเหตุเหตุการณ์ 📝
- OCR อ่านค่าจากรูปถ่ายผลตรวจ
- Export/Import JSON, Export CSV (รวมข้อมูลสต็อกยาแล้ว), พิมพ์ PDF
- ปุ่มแก้ไข/ลบ ในทุกตาราง

## 🔥 การตั้งค่า Firebase (ถ้ายังไม่เคยทำ)
ถ้าตั้งค่าไว้แล้ว **ข้ามได้เลย**
1. [console.firebase.google.com](https://console.firebase.google.com) → Authentication → เปิด **Anonymous** sign-in
2. Firestore Database → Rules → วางเนื้อหาจาก `firestore.rules` → Publish
3. Authentication → Settings → Authorized domains → เพิ่ม `<ชื่อผู้ใช้>.github.io`

## 📲 ติดตั้งเป็นแอปบนมือถือ
- **iPhone**: Safari → ปุ่มแชร์ ⬆️ → "เพิ่มไปยังหน้าจอโฮม"
- **Android**: ปุ่ม 📲 บน topbar หรือเมนู ⋮ → Install app

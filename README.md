# 🐱 สมุดสุขภาพทาโร่ (Taro Health Tracker)

เว็บแอปหน้าเดียวสำหรับบันทึกและติดตามค่าไต หัวใจ น้ำหนัก และ Resting Respiratory Rate (RRR) ของแมว

---

## ✨ อัปเดตล่าสุด: ปรับ "ประวัติการให้ยา" เป็น "ยาที่ใช้ประจำ"

### เปลี่ยนจากอะไร เป็นอะไร
เดิม: การ์ดยาบันทึกแบบ **Log เหตุการณ์** (วันที่ + การกระทำ เริ่ม/ปรับ/หยุด)
ใหม่: การ์ดยาบันทึกแบบ **รายการยาที่ใช้ประจำ** (Current Medications) ที่มีรายละเอียดครบกว่าเดิม:

| ฟิลด์ | คำอธิบาย |
|---|---|
| **ชื่อยา** | มี autocomplete ยาที่ใช้บ่อยในเคส HCM/CKD หรือพิมพ์เองได้ |
| **ขนาด (Dose)** | เช่น "1/4 เม็ด" |
| **ความถี่** | เช่น "วันละ 2 ครั้ง (เช้า-เย็น)" — มี autocomplete ให้เลือกด่วน |
| **เวลาที่กิน** | เช่น "08:00, 20:00" — มีปุ่มด่วน (chip) ให้กดเติมอัตโนมัติตามความถี่ที่เลือก |
| **วันที่เริ่มกิน** | วันที่เริ่มให้ยาตัวนี้ |
| **สถานะ** | กำลังใช้อยู่ / หยุดแล้ว (ถ้าหยุด จะมีช่องกรอกวันที่หยุดเพิ่ม) |
| **เชื่อมกับ Echo** | เลือกวันที่ Echo ที่เกี่ยวข้องได้ (ถ้ามี) |
| **หมายเหตุ** | บันทึกเพิ่มเติมอิสระ |

**ตารางแสดงผล:** ยาที่ "กำลังใช้อยู่" จะขึ้นแสดงก่อนเสมอ (เรียงจากวันที่เริ่มล่าสุด) ส่วนยาที่ "หยุดแล้ว" จะอยู่ด้านล่างและแสดงแบบจางลง (เพื่อให้เห็นภาพรวมยาปัจจุบันได้ไวที่สุด แต่ยังเก็บประวัติยาเก่าไว้ดูย้อนหลังได้)

### ⚠️ ข้อมูลเดิมของคุณไม่หายไปไหน
ถ้าคุณเคยบันทึกประวัติยาด้วยฟอร์มแบบเก่า (เริ่มยา/ปรับ/หยุด) ระบบจะ**แปลงข้อมูลเดิมให้อัตโนมัติ**เป็นรูปแบบใหม่ทันทีที่เปิดเว็บเวอร์ชันนี้ — ไม่ต้องกรอกซ้ำ แต่ช่อง "ความถี่" และ "เวลาที่กิน" ของรายการเก่าจะว่างไว้ก่อน (เพราะข้อมูลเดิมไม่มีฟิลด์นี้) กด "แก้ไข" ที่รายการนั้นแล้วเติมเพิ่มได้เลยครับ

## 🚀 วิธีอัปเดตโค้ด

### วิธีที่ 1: อัปโหลดผ่านเว็บ GitHub (ง่ายสุด)
1. เข้า repo `taro-health` บน GitHub
2. **Add file → Upload files** → ลากไฟล์ทั้งหมดวางทีเดียว (GitHub แทนที่ไฟล์ชื่อซ้ำให้อัตโนมัติ)
3. Commit changes → รอ 30–60 วิ
4. เปิด **Private/Incognito window ใหม่** เข้าลิงก์อีกครั้ง (กันแคชเก่า)

### วิธีที่ 2: Push ผ่าน Git command line
```bash
# ครั้งแรกเท่านั้น
cd ~/Desktop
git clone https://github.com/purinat7-tech/taro-health.git
cd taro-health

# ทุกครั้งที่ได้ไฟล์อัปเดตใหม่: วางไฟล์ทับในโฟลเดอร์นี้ แล้วรัน
git add -A
git commit -m "ปรับประวัติการให้ยาเป็นยาที่ใช้ประจำ"
git push origin main
```
ถ้า push แล้ว error ให้รัน `git pull origin main --rebase` ก่อนแล้ว push ใหม่

## 🧪 วิธีทดสอบ

1. เลื่อนไปที่การ์ด **"💊 ยาที่ใช้ประจำ"**
2. กรอกยาที่ทาโร่ใช้อยู่จริงตอนนี้ เช่น ยาป้องกันลิ่มเลือดที่หมอให้หลัง Echo — ใส่ขนาด, เลือกความถี่จาก autocomplete, กดปุ่มเวลาด่วน (chip) หรือพิมพ์เองก็ได้
3. กด "บันทึก" → ควรเห็นแถวใหม่ในตารางด้านบน พร้อมสถานะ "กำลังใช้อยู่" (สีเขียว)
4. ลองกด "แก้ไข" ที่แถวนั้น → ฟอร์มควรดึงค่าเดิมกลับมาให้แก้
5. ลองเปลี่ยนสถานะเป็น "หยุดแล้ว" แล้วบันทึก → แถวควรเลื่อนไปด้านล่างตารางและแสดงแบบจางลง พร้อมวันที่หยุดกำกับ

## 🔥 การตั้งค่า Firebase (ถ้ายังไม่เคยทำ)
ถ้าตั้งค่าไว้แล้ว **ข้ามได้เลย**

1. [console.firebase.google.com](https://console.firebase.google.com) → Authentication → เปิด **Anonymous** sign-in
2. Firestore Database → Rules → วางเนื้อหาจาก `firestore.rules` → Publish
3. Authentication → Settings → Authorized domains → เพิ่ม `<ชื่อผู้ใช้>.github.io`

## 📲 ติดตั้งเป็นแอปบนมือถือ
- **iPhone**: Safari → ปุ่มแชร์ ⬆️ → "เพิ่มไปยังหน้าจอโฮม"
- **Android**: ปุ่ม 📲 มุมขวาบน หรือเมนู ⋮ → Install app

## 👨‍👩‍👦 ใช้งานร่วมกันในครอบครัว
ทุกคนที่พิมพ์ **รหัสครอบครัวเดียวกัน** จะเห็นและบันทึกข้อมูลชุดเดียวกันแบบเรียลไทม์ ไม่ต้องสมัครสมาชิก

## ⚠️ ข้อควรรู้
- ข้อมูลเก็บบน Firestore ภายใต้ "รหัสครอบครัว" และแคชในเครื่องด้วย
- กด Export JSON/CSV เก็บสำรองเป็นระยะ
- เครื่องมือนี้ใช้เพื่อ**ติดตามแนวโน้ม**เท่านั้น ไม่ใช่การวินิจฉัยทางการแพทย์ การตัดสินใจเรื่องยา/การรักษาต้องปรึกษาสัตวแพทย์เสมอ

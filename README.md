# 🐱 Taro Health — สมุดสุขภาพทาโร่

เว็บแอปติดตามค่าไต หัวใจ น้ำหนัก และการหายใจของแมว — **ปรับดีไซน์ใหม่ทั้งหมด** เป็นสไตล์ fintech dashboard (sidebar + topbar + card-based UI) ตามภาพตัวอย่างที่ส่งมา

---

## ✨ สิ่งที่เปลี่ยนแปลงในการรีดีไซน์รอบนี้

### 1) โครงสร้างหน้าใหม่ทั้งหมด — Sidebar + Topbar + Pages
- **Sidebar ซ้ายมือ** (บนคอม/แท็บเล็ต): จัดกลุ่มเมนูเป็น Overview / Health Records / System พร้อม active state สีน้ำเงินไฮไลต์ตามตัวอย่าง
- **Topbar บนสุด**: ชื่อหน้าปัจจุบัน, badge สถานะซิงค์, ปุ่มติดตั้งแอป, ปุ่มสลับโหมดมืด/สว่าง, และ "โปรไฟล์" ทาโร่มุมขวา (คล้ายโปรไฟล์ผู้ใช้ในภาพตัวอย่าง)
- **แบ่งเนื้อหาเป็น 7 หน้า** สลับดูได้จากเมนู แทนที่จะเลื่อนหน้ายาวๆ แบบเดิม:
  1. 🏠 ภาพรวม (KPI รวม + แจ้งเตือน + การ์ดเฝ้าระวังหัวใจ)
  2. 📍 คลินิก/รพ.สัตว์
  3. 🫀 หัวใจ (Echo)
  4. 💊 ยาที่ใช้ประจำ
  5. 🫁 การหายใจ (RRR)
  6. 🧪 ผลเลือด/น้ำหนัก
  7. ⚙️ ข้อมูล & การใช้งาน

### 2) มือถือ: Bottom Nav แทน Sidebar
บนจอมือถือ sidebar จะซ่อนเป็นลิ้นชักที่เปิดผ่านปุ่ม ☰ (hamburger) แทน และมี **แถบเมนูด้านล่าง (bottom nav)** สำหรับ 5 หน้าหลักที่ใช้บ่อยที่สุด ให้สลับหน้าได้เร็วด้วยนิ้วโป้งข้างเดียวแบบแอปมือถือทั่วไป

### 3) โทนสีใหม่ — Fintech Blue
เปลี่ยนจากธีมพาสเทลมินต์-ชมพูเดิม เป็นโทน**น้ำเงิน-ขาว-เทาอ่อน** ตามภาพตัวอย่าง พร้อม:
- การ์ด KPI แบบ "primary card" ไฮไลต์สีน้ำเงินเต็ม (เหมือนปุ่ม "100€" ที่เลือกในภาพตัวอย่าง) ใช้กับค่า RRR ล่าสุดซึ่งเป็นค่าที่สำคัญที่สุด
- ปุ่ม, แท็บ, และ input ทั้งหมดปรับให้มีขอบมนสไตล์เดียวกัน
- **โหมดมืด**: พื้นหลังกรมท่าเข้มพร้อมลายเรขาคณิตทแยงมุมจางๆ ตามภาพตัวอย่างที่ 2 ที่ส่งมา

### 4) ปุ่มนับลมหายใจ (RRR Recorder) — ปรับสไตล์ใหม่
วงแหวนนับถอยหลังและปุ่มตรงกลางเปลี่ยนจากพาสเทลมินต์-ชมพู เป็นสีน้ำเงิน-แดงตามธีมใหม่ ยังคงฟังก์ชันเดิมทุกอย่าง (นับ 15/30/60 วินาที, แปลงเป็นครั้ง/นาที, บันทึกอัตโนมัติ)

---

## ✅ ฟีเจอร์เดิมทั้งหมดยังอยู่ครบ ไม่มีอะไรหายไป

- ระบบรหัสครอบครัว (Family PIN) + ซิงค์เรียลไทม์ผ่าน Firebase
- Popup แจ้งเตือนฉุกเฉินเมื่อ RRR > 45 พร้อมแนะนำคลินิกตามเวลาปัจจุบัน
- ประวัติ Echo พร้อมค่าตัวเลข IVSd/LA:Ao/LAFS/LVFS/LVPWd และช่องข้อความเต็ม/สรุป AI
- ยาที่ใช้ประจำ (ชื่อยา/ขนาด/ความถี่/เวลา/วันเริ่ม/สถานะ)
- กราฟผลเลือด (น้ำหนัก/Creatinine/BUN/ALT) พร้อมหมายเหตุเหตุการณ์ 📝
- OCR อ่านค่าจากรูปถ่ายผลตรวจ
- Export/Import JSON, Export CSV, พิมพ์ PDF
- ปุ่มแก้ไข/ลบ ในทุกตาราง

## 📁 ไฟล์ทั้งหมดที่ต้องอัปโหลด (13 ไฟล์)

| ไฟล์ | หมายเหตุ |
|---|---|
| `index.html` | 🔄 รีดีไซน์ใหม่ทั้งหมด (sidebar/topbar/pages) |
| `app.js` | 🔄 เพิ่ม logic นำทางหน้า (showPage, sidebar drawer) + สีธีมใหม่ในกราฟ |
| `sw.js` | 🔄 อัปเดต (cache v12) |
| `manifest.json` | 🔄 ปรับสีธีม PWA ให้ตรงกับดีไซน์ใหม่ |
| `firebase-config.js` | ✅ เหมือนเดิม ไม่ต้องแก้ |
| ไอคอนทั้งหมด (8 ไฟล์) | ✅ เหมือนเดิม |

*(`firestore.rules` ไม่ต้องอัปโหลด ใช้แค่ตอนตั้งค่า Firebase Console)*

## 🚀 วิธีอัปเดตโค้ด

### วิธีที่ 1: อัปโหลดผ่านเว็บ GitHub
1. เข้า repo `taro-health` → **Add file → Upload files** → ลากไฟล์ทั้งหมดวางทีเดียว
2. Commit changes → รอ 30–60 วิ
3. เปิด **Private/Incognito window ใหม่** เข้าลิงก์อีกครั้ง (กันแคชเก่า)

### วิธีที่ 2: Git command line
```bash
cd ~/Desktop/taro-health   # โฟลเดอร์ที่ clone ไว้แล้ว
# วางไฟล์ใหม่ทับในนี้ก่อน แล้วรัน
git add -A
git commit -m "รีดีไซน์ UI เป็นสไตล์ fintech dashboard (sidebar+topbar)"
git push origin main
```

## 🧪 วิธีทดสอบหลังอัปเดต

1. **เดสก์ท็อป**: ควรเห็น sidebar ซ้ายมือถาวร มีเมนู 7 รายการ คลิกแต่ละเมนูแล้วเนื้อหาด้านขวาต้องเปลี่ยนตาม พร้อมชื่อหน้าบน topbar อัปเดตตาม
2. **มือถือ**: ควรเห็นแถบเมนู 5 ปุ่มด้านล่างจอ กดปุ่ม ☰ มุมซ้ายบนควรมีลิ้นชักเมนูเลื่อนออกมาจากซ้าย พร้อมพื้นหลังมืดคลุมด้านหลัง
3. **โหมดมืด**: กดปุ่ม 🌓 มุมขวาบน ทั้ง sidebar และพื้นหลังหลักควรเปลี่ยนเป็นสีกรมท่าเข้มพร้อมลายทแยงมุมจางๆ
4. **ข้อมูลเดิม**: รหัสครอบครัวเดิม, ข้อมูล RRR/Echo/ยา/ผลเลือดที่เคยบันทึกไว้ควรยังอยู่ครบ ไม่มีอะไรหายไปจากการรีดีไซน์นี้

## 🔥 การตั้งค่า Firebase (ถ้ายังไม่เคยทำ)
ถ้าตั้งค่าไว้แล้ว **ข้ามได้เลย**
1. [console.firebase.google.com](https://console.firebase.google.com) → Authentication → เปิด **Anonymous** sign-in
2. Firestore Database → Rules → วางเนื้อหาจาก `firestore.rules` → Publish
3. Authentication → Settings → Authorized domains → เพิ่ม `<ชื่อผู้ใช้>.github.io`

## 📲 ติดตั้งเป็นแอปบนมือถือ
- **iPhone**: Safari → ปุ่มแชร์ ⬆️ → "เพิ่มไปยังหน้าจอโฮม"
- **Android**: ปุ่ม 📲 บน topbar หรือเมนู ⋮ → Install app

## ⚠️ ข้อควรรู้

# 🐱 สมุดสุขภาพทาโร่ (Taro Health Tracker)

เว็บแอปหน้าเดียวสำหรับบันทึกและติดตามค่าไต หัวใจ น้ำหนัก และ Resting Respiratory Rate (RRR) ของแมว

---

## ✨ อัปเดตล่าสุด: เพิ่มระบบติดตามหัวใจแบบเต็มรูปแบบ

### 1) 🫀 ประวัติ Echocardiogram (อัลตราซาวด์หัวใจ)
บันทึกผล Echo แต่ละครั้ง พร้อม:
- ค่าตัวเลขสำคัญที่ระบบจะเทียบเกณฑ์ให้อัตโนมัติ: **IVSd** (ผนังหัวใจหนา), **LA/Ao ratio**, **LAFS** (การบีบตัวห้องบนซ้าย) — ใช้เกณฑ์ตรงจากที่สัตวแพทย์ระบุในเคสนี้ (IVSd ≤0.6cm, LA/Ao 1.6–1.7, LAFS ≥25%) พร้อมช่อง **LVFS** และ **LVPWd** ไว้บันทึกเสริม (ยังไม่ตัดสินผิด/ถูกอัตโนมัติเพราะหมอยังไม่ได้ให้เกณฑ์ชัดเจนของสองค่านี้ในเคสนี้)
- ระดับความเสี่ยงลิ่มเลือด (ATE) และการวินิจฉัย (HCM, HCM phenotype, RCM, DCM, ARVC, ระยะท้าย ฯลฯ)
- กล่องข้อความยาว 2 กล่องแยกกัน: **📄 ผลเต็มจากหมอ** (paste ข้อความดิบจากหมอ) และ **🤖 สรุปจาก AI** (paste สรุปที่ให้ AI ช่วยอ่านผลให้)
- กราฟแนวโน้มแบบสลับแท็บดูได้ (IVSd / LA:Ao / LAFS / LVFS / LVPWd)
- ปุ่ม **แก้ไข** / **ลบ** ในแต่ละบันทึก

ค่า **LA/Ao ratio** และ **ความเสี่ยงลิ่มเลือดล่าสุด** จะขึ้นเป็นการ์ด KPI ที่ด้านบนสุดของหน้าเว็บด้วย และมีแบนเนอร์สรุปสั้นๆ ในการ์ด "เฝ้าระวังโรคหัวใจ" บอกผลล่าสุดโดยอัตโนมัติ

### 2) 💊 ประวัติการให้ยา
Log ยาที่เริ่ม/ปรับขนาด/หยุด แบบตาราง พร้อม:
- ช่องกรอกชื่อยาแบบมี autocomplete ยาที่ใช้บ่อยในเคส HCM/CKD (Clopidogrel, Furosemide, Pimobendan, Spironolactone, Benazepril, Enalapril, Telmisartan, Atenolol) หรือพิมพ์ชื่อยาอื่นเองได้
- เชื่อมโยงกับ "วันที่ Echo" ที่เกี่ยวข้องได้ (เลือกจาก dropdown อัตโนมัติตามประวัติ Echo ที่มี)
- ปุ่มแก้ไข/ลบในแต่ละแถว

## 📝 สรุปผล Echo ที่ผมช่วยเขียนให้ (พร้อม copy ไปวางในแอปได้เลย)

จากข้อความที่หมอส่งมา นี่คือสรุปที่ผมเรียบเรียงให้ — สามารถ copy ไปวางในช่อง **"🤖 สรุปจาก AI"** ได้เลยเมื่อบันทึกผล Echo ครั้งนี้ (อย่าลืมใส่วันที่ตรวจจริงด้วย เพราะข้อความแชทมีแค่เวลา ไม่มีวันที่ชัดเจน):

> พบกล้ามเนื้อหัวใจห้องล่างซ้ายหนาตัวผิดปกติ (IVSd 0.8 cm, ปกติไม่เกิน 0.6 cm) ร่วมกับหัวใจห้องบนซ้ายโตรุนแรง (LA/Ao 2.58, ปกติ 1.6–1.7) วินิจฉัยเป็นโรคกล้ามเนื้อหัวใจหนาตัวร่วมกับหัวใจห้องบนซ้ายโต (HCM) การบีบตัวห้องล่างซ้าย (LVFS) ยังดีหรือสูงกว่าปกติ แต่การบีบตัวห้องบนซ้าย (LAFS) ต่ำมากที่ 12% (ปกติ 25–28%+) บ่งชี้ภาวะห้องบนซ้ายล้า ความเสี่ยงหลัก 2 ประการ: (1) ลิ่มเลือดอุดตัน (thromboembolism) ความเสี่ยงสูง แม้ยังไม่พบลิ่มเลือดในห้องหัวใจขณะนี้ เริ่มยาป้องกันลิ่มเลือดแล้ว (2) ภาวะหัวใจล้มเหลว/น้ำท่วมปอด จาก x-ray พบน้ำในปอดร่วมกับปอดอักเสบเล็กน้อย เริ่มยาขับน้ำแล้ว Function บีบตัว-คลายตัวของหัวใจโดยรวมยังประเมินไม่สมบูรณ์ ต้องรอแมวสงบก่อนนัดอัลตราซาวด์ซ้ำ

**ค่าที่แนะนำให้กรอกในฟอร์ม Echo สำหรับครั้งนี้:**
| ช่อง | ค่า |
|---|---|
| IVSd | 0.8 |
| LA/Ao ratio | 2.58 |
| LAFS | 12 |
| ความเสี่ยงลิ่มเลือด | สูง |
| การวินิจฉัย | HCM |
| สถานะ Function อื่นๆ | รอสัตว์สงบก่อนอัลตราซาวด์ประเมินซ้ำ |

## 🚀 วิธีอัปเดตโค้ด — 2 วิธีเลือกได้

### วิธีที่ 1: อัปโหลดผ่านเว็บ GitHub (แบบเดิม ง่ายสุด)
1. เข้า repo `taro-health` บน GitHub
2. **Add file → Upload files** → ลากไฟล์ทั้งหมดวางทีเดียว (GitHub แทนที่ไฟล์ชื่อซ้ำให้อัตโนมัติ)
3. Commit changes → รอ 30–60 วิ
4. เปิด **Private/Incognito window ใหม่** เข้าลิงก์อีกครั้ง (กันแคชเก่า)

### วิธีที่ 2: 🔧 Push โค้ดผ่าน Git command line (ทางเลือกสำหรับคนถนัดสาย dev)

**ครั้งแรก — ติดตั้ง Git และ clone repo (ทำครั้งเดียว)**

1. ติดตั้ง Git ถ้ายังไม่มี:
   - Mac: เปิด Terminal พิมพ์ `git --version` ถ้ายังไม่มีจะมี popup ให้ติดตั้งอัตโนมัติ
   - Windows: ดาวน์โหลดจาก [git-scm.com](https://git-scm.com/downloads) แล้วติดตั้งตามปกติ
2. เปิด Terminal (Mac) หรือ Git Bash (Windows) แล้ว clone repo:
   ```bash
   cd ~/Desktop
   git clone https://github.com/purinat7-tech/taro-health.git
   cd taro-health
   ```
3. ตั้งค่าชื่อ/อีเมลของคุณ (ใช้ครั้งแรกครั้งเดียว):
   ```bash
   git config --global user.name "ชื่อคุณ"
   git config --global user.email "อีเมลที่ใช้สมัคร GitHub"
   ```

**ทุกครั้งที่ผมส่งไฟล์อัปเดตให้ใหม่ — ทำตามนี้**

1. แตะไฟล์ zip ที่ได้รับ แล้วคัดลอกไฟล์ทั้งหมดข้างในไปวางทับในโฟลเดอร์ `taro-health` ที่ clone ไว้ (ทับของเดิมได้เลย)
2. เปิด Terminal/Git Bash ในโฟลเดอร์นั้น (หรือ `cd` เข้าไปใหม่) แล้วรันตามลำดับ:
   ```bash
   git add -A
   git commit -m "อัปเดต: เพิ่มระบบ Echo และ Medication log"
   git push origin main
   ```
3. เสร็จแล้ว! รอ 30–60 วิให้ GitHub Pages redeploy แล้วเปิดเว็บใหม่ตามปกติ

**เช็คสถานะก่อน commit ได้ด้วยคำสั่ง:**
```bash
git status        # ดูว่าไฟล์ไหนเปลี่ยนไปบ้าง
git diff          # ดูรายละเอียดที่เปลี่ยน (กด q เพื่อออก)
```

**ถ้า push แล้วขึ้น error "failed to push"** (มักเกิดเมื่อมีคน/เครื่องอื่น push ไปก่อน) ให้ดึงของใหม่มารวมก่อน:
```bash
git pull origin main --rebase
git push origin main
```

> 💡 วิธีที่ 2 นี้เหมาะถ้าคุณจะแก้โค้ดเองบ้าง หรืออยากมีประวัติการเปลี่ยนแปลง (version history) ที่ดูย้อนหลังได้ทุกครั้ง — ถ้าไม่ถนัด ใช้วิธีที่ 1 ก็ได้ผลลัพธ์เหมือนกันทุกประการ

## 🧪 วิธีทดสอบฟีเจอร์ใหม่

**บันทึกผล Echo ของทาโร่ครั้งนี้:** เลื่อนไปที่การ์ด "🫀 ประวัติ Echocardiogram" กรอกวันที่ตรวจจริง + ค่าตามตารางด้านบน + วาง "สรุปจาก AI" ที่เตรียมไว้ให้ + วางข้อความเต็มจากหมอในช่อง "ผลเต็มจากหมอ" (copy จากแชทมาได้เลย) → กด "บันทึกผล Echo"

**บันทึกยาที่เริ่มให้:** เลื่อนไปที่การ์ด "💊 ประวัติการให้ยา" → กรอกยาป้องกันลิ่มเลือดที่คุณพ่อให้ไปแล้ว + ยาขับน้ำ → เลือก "เชื่อมกับ Echo วันที่" เป็นวันที่คุณเพิ่งบันทึกไป

**เช็ค KPI card:** หลังบันทึกแล้ว เลื่อนขึ้นบนสุด ควรเห็นการ์ด "LA/Ao ratio" และ "ความเสี่ยงลิ่มเลือด (ATE)" ขึ้นมาใหม่ พร้อมแบนเนอร์สรุปในการ์ด "เฝ้าระวังโรคหัวใจ"

ถ้าตั้งค่าไว้แล้ว **ข้ามได้เลย**

## 👨‍👩‍👦 ใช้งานร่วมกันในครอบครัว
ทุกคนที่พิมพ์ **รหัสครอบครัวเดียวกัน** จะเห็นและบันทึกข้อมูลชุดเดียวกันแบบเรียลไทม์ ไม่ต้องสมัครสมาชิก

## ⚠️ ข้อควรรู้
- ข้อมูลเก็บบน Firestore ภายใต้ "รหัสครอบครัว" และแคชในเครื่องด้วย
- กด Export JSON/CSV เก็บสำรองเป็นระยะ
- ค่าอ้างอิงของ IVSd/LA:Ao/LAFS ที่ใช้ในแอปนี้อ้างอิงจากคำอธิบายของสัตวแพทย์ที่ดูแลเคสนี้โดยตรง — หากสัตวแพทย์ท่านอื่นให้เกณฑ์ต่างไป สามารถแก้ไขได้ที่ตัวแปร `ECHO_PARAMS` ต้นไฟล์ `app.js`
- เครื่องมือนี้ใช้เพื่อ**ติดตามแนวโน้ม**เท่านั้น ไม่ใช่การวินิจฉัยทางการแพทย์ การตัดสินใจเรื่องยา/การรักษาต้องปรึกษาสัตวแพทย์เสมอ

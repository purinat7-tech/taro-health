# 🐱 สมุดสุขภาพทาโร่ (Taro Health Tracker)

เว็บแอปหน้าเดียวสำหรับบันทึกและติดตามค่าไต น้ำหนัก และ Resting Respiratory Rate (RRR) ของแมว

---

## ✨ อัปเดตล่าสุด (3 จุด)

### 1) 📝 หมายเหตุเหตุการณ์ในผลเลือด (เช่น ฉีดยาขับน้ำ)
ตอนนี้ตอนบันทึกผลเลือดแต่ละครั้ง จะมีช่อง **"📝 หมายเหตุวันนี้"** เพิ่มเข้ามา ใช้บันทึกเหตุการณ์ที่อาจกระทบค่าตรวจ เช่น
- "ฉีด Lasix เช้านี้ก่อนเจาะเลือด"
- "งดน้ำ 8 ชม.ก่อนตรวจ"
- "ปรับยาไตใหม่เมื่อ 3 วันก่อน"

หมายเหตุนี้จะแสดง:
- เป็น**แถวสีม่วง**ใต้ตารางผลเลือด (ตรงคอลัมน์วันที่นั้นๆ)
- เป็น**ไอคอน 📝ในกราฟ**พร้อมเส้นประชี้ไปยังจุดข้อมูลวันนั้น — เอาเมาส์/นิ้วแตะไอคอนจะเห็นข้อความเต็ม
ทำให้เห็นชัดว่าค่าไตที่พุ่งขึ้นวันนั้นอาจเป็นเพราะยา ไม่ใช่โรคแย่ลงจริง

### 2) 🎨 แก้ไอคอนแอปให้เต็มกรอบ (ไม่มีขอบขาว/mint ไม่เต็ม)
ไอคอนเดิมที่ใช้ตอน Add to Home Screen บน iPhone มีปัญหาสีมินต์ไม่เต็มกรอบสี่เหลี่ยมมุมโค้ง (เห็นเป็นวงกลมลอยอยู่กลางกรอบขาว)
**แก้ใหม่แล้ว** — ไอคอนตอนนี้เป็นแบบ **full-bleed** (สีเต็มพอดีกรอบทุกด้าน ไม่มีขอบขาว) ตามมาตรฐานไอคอน iOS/Android ที่ถูกต้อง (ระบบปฏิบัติการจะเป็นผู้ปัดมุมโค้งเองอัตโนมัติ ไม่ต้องปัดมุมมาเองในรูป)

**⚠️ สำคัญ: ต้องลบไอคอนเดิมออกจากหน้าจอโฮมก่อน แล้วค่อย Add to Home Screen ใหม่**
เพราะ iOS จะแคชไอคอนเดิมไว้ ถ้าไม่ลบแล้วเพิ่มใหม่ จะยังเห็นไอคอนเก่าอยู่ ขั้นตอน:
1. กดค้างที่ไอคอนแอปเดิมบนหน้าจอโฮม → เลือก "ลบแอป" (Remove App)
2. เข้าเว็บผ่าน Safari ใหม่ → กดปุ่มแชร์ ⬆️ → "เพิ่มไปยังหน้าจอโฮม" อีกครั้ง
3. ควรเห็นไอคอนสีมินต์เต็มกรอบพอดีแล้ว

### 3) 📱 แก้ Layout มือถือที่ input ซ้อนกัน
ปรับฟอร์มกรอกข้อมูลทั้งหมด (RRR และผลเลือด) ให้ **แต่ละช่องซ้อนกันเต็มความกว้างแบบมีระยะห่างชัดเจน** บนหน้าจอมือถือ (breakpoint ≤640px) แทนที่จะพยายามเรียงชิดกันจนช่องอินพุตทับกันเหมือนก่อนหน้านี้ ทดสอบแล้วบน iPhone viewport ไม่มีอาการซ้อนทับอีก

## 🚀 วิธีอัปโหลด
1. เข้า repo `taro-health` บน GitHub
2. **Add file → Upload files** → ลากไฟล์ทั้งหมด (ไม่รวม `icon-1024.png` และ `firestore.rules` ก็ได้) วางทีเดียว
3. Commit changes → รอ 30–60 วิ
4. **ลบไอคอนแอปเดิมออกจากหน้าจอโฮม iPhone ก่อน** (ตามขั้นตอนข้อ 2 ด้านบน) แล้วเปิด Private window เข้าลิงก์ใหม่ → Add to Home Screen ใหม่

## 🧪 วิธีทดสอบฟีเจอร์ใหม่

**ทดสอบหมายเหตุ:** กรอกผลเลือดพร้อมพิมพ์ข้อความในช่อง "📝 หมายเหตุวันนี้" เช่น "ฉีดยาขับน้ำ" แล้วกดบันทึกผล → เลื่อนดูตารางด้านบน จะเห็นแถวสีม่วง "📝 หมายเหตุ" ใต้ตาราง และเห็นไอคอน 📝 อยู่เหนือจุดข้อมูลในกราฟ

**ทดสอบไอคอน:** ลบไอคอนเดิม (ถ้ามี) → Add to Home Screen ใหม่ → เช็คว่าสีมินต์เต็มกรอบสี่เหลี่ยมมุมโค้งพอดี ไม่มีขอบขาวเหลือ

**ทดสอบ mobile layout:** เปิดเว็บบน iPhone จริง เลื่อนไปที่ฟอร์มกรอก RRR หรือผลเลือด แต่ละช่องควรเรียงเป็นแถวเดี่ยว เต็มความกว้าง มีระยะห่างชัดเจน ไม่ทับกัน

## 🔥 การตั้งค่า Firebase (ถ้ายังไม่เคยทำ)
ถ้าตั้งค่าไว้แล้ว **ข้ามได้เลย**

1. [console.firebase.google.com](https://console.firebase.google.com) → Authentication → เปิด **Anonymous** sign-in
2. Firestore Database → Rules → วางเนื้อหาจาก `firestore.rules` → Publish
3. Authentication → Settings → Authorized domains → เพิ่ม `<ชื่อผู้ใช้>.github.io`

## 📲 ติดตั้งเป็นแอปบนมือถือ
- **iPhone**: Safari → ปุ่มแชร์ ⬆️ → "เพิ่มไปยังหน้าจอโฮม"
- **Android**: ปุ่ม 📲 มุมขวาบน หรือเมนู ⋮ → Install app

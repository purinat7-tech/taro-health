# 🐱 สมุดสุขภาพทาโร่ (Taro Health Tracker)

เว็บแอปหน้าเดียวสำหรับบันทึกและติดตามค่าไต น้ำหนัก และ Resting Respiratory Rate (RRR) ของแมว
ดีไซน์พาสเทลอบอุ่น ใช้อวาตาร์การ์ตูนแมวสไตล์จิบิ (คลีน ไม่มีเครื่องประดับ) พร้อมปุ่ม "recorder"
นับลมหายใจขนาดใหญ่สำหรับมือถือ เข้าใช้งานร่วมกันได้ทั้งครอบครัวผ่าน **รหัสครอบครัว** เดียวกัน

---

## ⚠️ สำคัญมาก: นี่คือไฟล์เวอร์ชัน "รวมทุกฟีเจอร์" ล่าสุด

ก่อนหน้านี้เกิดความสับสนเพราะมีการอัปเดตแยกกันหลายรอบจนบางฟีเจอร์หลุดหายไป
**ไฟล์ชุดนี้คือเวอร์ชันล่าสุดที่รวมทุกอย่างที่เคยขอไว้ทั้งหมดในที่เดียว** ได้แก่:

| ฟีเจอร์ | สถานะ |
|---|---|
| ดีไซน์พาสเทลครีม-มินต์-ชมพู | ✅ |
| อวาตาร์แมวจิบิ **คลีน ไม่มีโบว์/เครื่องประดับ** | ✅ (วาดใหม่รอบนี้) |
| ปุ่มนับลมหายใจ (Recorder) ขนาดใหญ่ + progress ring | ✅ |
| กราฟ RRR ปรับสเกลสูงสุด ~80 (ไม่พุ่งเกิน 1000 แบบเดิม) | ✅ |
| การ์ดเฝ้าระวังโรคหัวใจ & ลิ่มเลือดอุดตัน (ATE) | ✅ |
| ตารางค่าต่างๆ จัดกึ่งกลางคอลัมน์ | ✅ |
| OCR อ่านค่าจากรูปถ่ายผลตรวจ | ✅ |
| **🚨 Popup แจ้งเตือนทันทีเมื่อ RRR เกิน 45** | ✅ (เพิ่มใหม่รอบนี้) |
| ระบบรหัสครอบครัว (ไม่ต้องสมัครสมาชิก) + ซิงค์เรียลไทม์ผ่าน Firebase | ✅ |

**แนะนำ: ลบไฟล์เดิมทั้งหมดใน repo แล้วอัปโหลดไฟล์ชุดนี้ทับใหม่ทั้งหมด** เพื่อไม่ให้มีไฟล์เก่าค้างปนกัน

## 🚀 วิธีอัปโหลด (แนะนำ: ลบเก่าทั้งหมด อัปโหลดใหม่)

1. เข้า repository `taro-health` บน GitHub
2. **ลบไฟล์เก่าทั้งหมด** — เลือกไฟล์ที่ไม่ใช่ `README.md` แล้วลบทีละไฟล์ (หรือคลิกไฟล์ → ไอคอนถังขยะ)
3. กด **Add file → Upload files**
4. ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (13 ไฟล์ ไม่รวม `firestore.rules`) ไปวางทีเดียว
5. เลื่อนลงล่าง กด **Commit changes**
6. รอ ~30–60 วินาที ให้ GitHub Pages redeploy
7. **สำคัญ:** เปิด **Private/Incognito window** ใหม่ทั้งหมด แล้วเข้าลิงก์อีกครั้ง เพื่อเลี่ยงแคชเก่า

## 🚨 วิธีทดสอบ Popup แจ้งเตือน RRR

Popup จะเด้งขึ้น **เฉพาะเมื่อค่า RRR ล่าสุดที่บันทึกเกิน 45 ครั้ง/นาที** และเป็นค่าที่ยังไม่เคยแจ้งเตือนบนอุปกรณ์นั้นมาก่อน

**วิธีทดสอบ:**
1. เลื่อนไปที่ช่องกรอก RRR ในการ์ด "Resting Respiratory Rate"
2. เลือกวันที่ใดก็ได้ที่ยังไม่เคยมีข้อมูล + กรอกค่า เช่น **50**
3. กด **บันทึก** → popup สีแดงควรเด้งขึ้นทันที พร้อมคำแนะนำ

**หมายเหตุ:** ถ้าค่าล่าสุดที่มีอยู่แล้วต่ำกว่า 45 (เช่น 27) popup จะไม่ขึ้น — เป็นพฤติกรรมที่ถูกต้อง ไม่ใช่บั๊ก
Popup ยังทำงานได้แม้ค่าจะถูกกรอกจากอุปกรณ์อื่น (เช่น พ่อ-แม่กรอกตอนคุณไม่อยู่ แล้วซิงค์เข้ามาที่เครื่องคุณ)

## 📷 วิธีใช้ฟีเจอร์ OCR อ่านค่าจากรูป

1. ในการ์ด "ผลเลือด – ค่าไต / ตับ" กดปุ่ม **"เลือกรูป"** ในกล่องเขียวประ
2. เลือกถ่ายรูปใหม่หรือเลือกรูปที่มีอยู่
3. รอ 10–30 วินาที ระบบจะประมวลผลด้วย Tesseract.js (ทำงานในเบราว์เซอร์ล้วนๆ ไม่ส่งรูปออกไปไหน)
4. ตรวจสอบตัวเลขที่เติมให้ก่อนกด "บันทึกผล" เสมอ

## 🔥 การตั้งค่า Firebase (ถ้ายังไม่เคยทำ)
ถ้าตั้งค่าไว้แล้วจากก่อนหน้านี้ **ข้ามส่วนนี้ได้เลย** — `firebase-config.js` ใช้ค่าเดิมของโปรเจกต์ `taro-health-monitoring`

1. [console.firebase.google.com](https://console.firebase.google.com) → Add project
2. Authentication → Sign-in method → เปิด **Anonymous**
3. Firestore Database → Create database → Production mode
4. แท็บ Rules → วางเนื้อหาจาก `firestore.rules` → Publish
5. `</>` Web app → คัดลอก config → ใส่ใน `firebase-config.js`
6. Authentication → Settings → Authorized domains → เพิ่ม `<ชื่อผู้ใช้>.github.io`

## 👨‍👩‍👦 ใช้งานร่วมกันในครอบครัว
ทุกคนที่พิมพ์ **รหัสครอบครัวเดียวกัน** จะเห็นและบันทึกข้อมูลชุดเดียวกันแบบเรียลไทม์ ไม่ต้องสมัครสมาชิก

## 🧹 ถ้าอัปเดตแล้วเว็บยังเหมือนเดิม (แคชค้าง)
1. ปิดแท็บ Private window เดิมทั้งหมด
2. Safari: Settings → Advanced → Website Data → ค้นหา `github.io` → Delete
3. Chrome: F12 → Application → Clear site data
4. เปิด Private/Incognito window ใหม่ → เข้าลิงก์อีกครั้ง
5. ตรวจสอบว่าไฟล์ถูกอัปโหลดจริง: เปิดไฟล์ `app.js` ใน repo → ค้นหาคำว่า `checkEmergency` (ต้องเจอ)

## ⚠️ ข้อควรรู้
- ข้อมูลเก็บบน Firestore ภายใต้ "รหัสครอบครัว" และแคชในเครื่องด้วย
- กด Export JSON/CSV เก็บสำรองเป็นระยะ
- เครื่องมือนี้ใช้เพื่อ**ติดตามแนวโน้ม**เท่านั้น ไม่ใช่การวินิจฉัยทางการแพทย์
- ค่า OCR เป็นเพียงตัวช่วย ไม่ใช่ค่าที่รับประกันความถูกต้อง 100%

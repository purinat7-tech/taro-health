# 🐱 สมุดสุขภาพทาโร่ (Taro Health Tracker)

เว็บแอปหน้าเดียวสำหรับบันทึกและติดตามค่าไต น้ำหนัก และ Resting Respiratory Rate (RRR) ของแมว

---

## ✨ อัปเดตล่าสุด (3 จุด)

### 1) 📊 การ์ดด้านบนแสดง "ค่าล่าสุดที่มีการบันทึกจริง" ของแต่ละรายการ
**บั๊กเดิม:** การ์ด KPI เคยดึงค่าจาก "แถวข้อมูลล่าสุดตามวันที่" เพียงแถวเดียว ถ้าแถวนั้นมีแค่น้ำหนัก (ไม่ได้เจาะเลือด) การ์ด Creatinine/BUN/ALT จะโชว์ "–" ทั้งที่จริงมีค่าจากการตรวจครั้งก่อนหน้า

**แก้แล้ว:** ตอนนี้แต่ละการ์ด (Creatinine, BUN, ALT/GPT, น้ำหนัก) จะค้นหา**ค่าที่มีการบันทึกจริงล่าสุดของตัวเองแยกกัน** ไม่สนใจว่าค่าตัวอื่นจะมีในวันเดียวกันหรือไม่ พร้อมโชว์ **"ล่าสุด xx/xx"** กำกับใต้ค่าให้รู้ว่าเป็นข้อมูลของวันไหน

### 2) 📈 กราฟแสดงครบทุกจุดที่บันทึกไว้ + รวมน้ำหนักเข้ามาเป็นแท็บเดียวกัน
**บั๊กเดิม:** กราฟ Creatinine/BUN/ALT เคยคำนวณตำแหน่งแกน X ผิด ทำให้จุดข้อมูลที่อยู่ถัดจากช่วงที่มีค่าว่าง (เช่น ตรวจแค่น้ำหนักบางครั้ง) ถูกดันตกขอบกราฟไปทางขวา มองไม่เห็น (ทำให้ดูเหมือนมีข้อมูลแค่ 3 จุด)

**แก้แล้ว:** ปรับให้ตำแหน่งแกน X อ้างอิงจาก**จำนวนวันที่บันทึกทั้งหมด**เสมอ ไม่ใช่แค่จำนวนจุดที่มีค่า ทำให้ทุกจุดที่เคยบันทึกไว้แสดงผลถูกต้องครบตามตำแหน่งวันที่จริง

**รวมน้ำหนักเข้ามาเป็นแท็บเดียวกัน:** ย้ายกราฟน้ำหนัก (เดิมอยู่การ์ดแยกด้านล่าง) มารวมเป็นแท็บแรกในการ์ด "ผลตรวจ" เดียวกับ Creatinine / BUN / ALT-GPT — สลับดูได้จากปุ่มแท็บด้านบนกราฟ ไม่ต้องเลื่อนหน้าจอไปมา

### 3) ✏️ ปุ่ม "แก้ไข" สำหรับย้อนกลับไปเพิ่ม/แก้หมายเหตุ
เพิ่มปุ่ม **"แก้ไข"** (กรอบม่วง) คู่กับปุ่ม "ลบ" ใต้ตารางผลตรวจแต่ละวัน — กดแล้วค่าของวันนั้นจะถูกดึงกลับมาใส่ในฟอร์มด้านบนให้แก้ไขได้ทันที (รวมถึงเพิ่ม/แก้ 📝 หมายเหตุย้อนหลัง เช่น ลืมใส่ตอนบันทึกครั้งแรกว่าฉีดยาขับน้ำ) กดปุ่ม "บันทึกการแก้ไข" เพื่อบันทึกทับ หรือกด "ยกเลิกแก้ไข" เพื่อเลิกและเริ่มกรอกใหม่

## 🚀 วิธีอัปโหลด
1. เข้า repo `taro-health` บน GitHub
2. **Add file → Upload files** → ลากไฟล์ทั้งหมดวางทีเดียว (GitHub แทนที่ไฟล์ชื่อซ้ำให้อัตโนมัติ)
3. Commit changes → รอ 30–60 วิ
4. เปิด **Private/Incognito window ใหม่** เข้าลิงก์อีกครั้ง (กันแคชเก่า)

## 🧪 วิธีทดสอบฟีเจอร์ใหม่

**ทดสอบ KPI:** ถ้าคุณเคยมีวันที่บันทึกแค่น้ำหนักอย่างเดียว (ไม่มีผลเลือด) การ์ด Creatinine/BUN/ALT ควรยังโชว์ค่าจากการตรวจครั้งก่อนหน้า พร้อมข้อความ "ล่าสุด xx/xx" กำกับ ไม่ใช่ "–"

**ทดสอบกราฟ:** เข้าไปที่การ์ด "🧪 ผลตรวจ – น้ำหนัก / ค่าไต / ตับ" ลองกดสลับแท็บ น้ำหนัก / Creatinine / BUN / ALT-GPT ทีละอัน ทุกจุดข้อมูลที่เคยบันทึกไว้ควรแสดงครบ กระจายตามตำแหน่งวันที่ถูกต้อง ไม่มีจุดหายไปแม้จะมีบางวันที่ไม่ได้กรอกครบทุกค่า

**ทดสอบปุ่มแก้ไข:** เลื่อนลงมาที่ตารางใต้กราฟ กดปุ่ม "แก้ไข" ใต้คอลัมน์วันที่ใดก็ได้ → ฟอร์มด้านบนควรเด้งค่าของวันนั้นมาให้แก้ไข ลองพิมพ์อะไรในช่องหมายเหตุ แล้วกด "บันทึกการแก้ไข" → ค่าควรอัปเดตในตาราง/กราฟทันที

## 🔥 การตั้งค่า Firebase (ถ้ายังไม่เคยทำ)
ถ้าตั้งค่าไว้แล้ว **ข้ามได้เลย**

1. [console.firebase.google.com](https://console.firebase.google.com) → Authentication → เปิด **Anonymous** sign-in
2. Firestore Database → Rules → วางเนื้อหาจาก `firestore.rules` → Publish
3. Authentication → Settings → Authorized domains → เพิ่ม `<ชื่อผู้ใช้>.github.io`
